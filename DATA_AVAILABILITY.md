# Data and Code Availability

This repository provides the source code, figure-generation materials,
manuscript source files, and lightweight processed result summaries supporting
the paper.

## Included in this repository

- BC-DRCFAR source code and experiment entry points.
- Processed CSV summaries used by the manuscript figures and tables.
- Selected audit reports documenting the final evidence chain.
- LaTeX manuscript source, bibliography, and figure PDFs.

## Public data sources

The raw public radar datasets used by the study are not redistributed in this
repository. They should be obtained from their original providers:

- McMaster University IPIX radar sea-clutter dataset.
- Public Birmingham maritime radar data used for external raw-data audit.

The original dataset providers retain control over data distribution and usage
terms. Users should cite and follow the terms of those providers when reusing
the raw radar data.
